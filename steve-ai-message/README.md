# STEVE IA Message API

Backend Node.js pour STEVE IA Message.

Routes:
- GET /api/health
- GET /api/connectors
- POST /api/ai/suggestions
- POST /api/ai/reply

Render:
- Build: `cd steve-ai-message && npm install`
- Start: `cd steve-ai-message && npm start`

Variables:
- `OPENAI_API_KEY`
- `OPENAI_MODEL=gpt-5.6-luna`

Ne jamais committer une vraie clé API.
